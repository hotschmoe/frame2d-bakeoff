# Fixtures

`p1/F01..F15.json` and `p2/F21..F25.json` are generated by `harness/make_fixtures.py`. Expected values are computed from closed-form beam theory at full float precision, not copied from the rounded numbers in SPEC §6. Edit the script, not the JSON.

Each file is a model (SPEC §5.1) plus an `expect` list:

| Entry | Meaning |
|-------|---------|
| `{"path": "/load_cases/0/displacements/1/uy", "value": -0.026}` | numeric check, relative 1e-9, absolute floor 1e-12 |
| `{"path": "/warnings/0/warning", "value": "auto_restrained"}` | exact string match |
| `{"path": "/warnings", "len": 1}` | array length |
| `{"error": "unstable"}` | CLI exits 2 and prints this error code |

Pointers index into the results after arrays are sorted by id. `displacements` has every node; `reactions` has one entry per node with a restrained DOF; `stations[k]` is at x = k·L/10. "Midspan" in two-member beams is member 1, station 10.

`golden/` is empty until the first stack passes P1. See SPEC §6.3 for how the goldens are produced and verified.
